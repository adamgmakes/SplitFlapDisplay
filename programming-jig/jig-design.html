Flash-and-Address Programming Jig

Seat a bare driver board, press the head down, and seven spring pins contact everything needed to flash the firmware, assign the module's bus address, and verify it — one seating per board, no soldering per board. Printable model: programming-jig/jig.scad.

Contact layout — top view

Coordinates in mm from the board's top-left corner (component side up, silkscreen upright), taken from the V4 KiCad layout. Every target is a Ø1.0 mm plated hole, so spear-tip pogo pins self-center — print tolerance is not critical.

UPDI Friend switch stays on 3V, and its red power wire stays unconnected — the board powers itself from the 12 V pad through its own regulators, exactly as it will in the display.

Per-board cycle (~90 s)

  1. Seat board on the pegs, press the head down, switch 12 V on.
  2. Wait ~15 s — with no motor attached, the boot homing attempt runs to its safety limit before the module listens.
  3. Flash — Upload Using Programmer in Arduino IDE (identical binary for every board; ~10 s).
  4. Address — the board is alone on this bus, so broadcast: send m*i7 to make it module 7.
  5. Verify — send m7d; a reply (m7d:…) proves both flash and address.
  6. 12 V off, lift, label the board, next.

Addresses stick because the firmware writes HARDCODED_ID to EEPROM only on a board's very first boot; after that the EEPROM value always wins, and the i command rewrites it permanently. Set Arduino's Tools → Save EEPROM to retained so future firmware updates keep addresses and calibration too.
